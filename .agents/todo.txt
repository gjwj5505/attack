C subset rewrite

docker로 연결해서 실행 파일 계속 호출하면 오래걸리니까. 한 번만 실행해서 socket 연결하던 아예 같이 빌드하던 방법 찾기

- Keep the project temporarily language-only:
  - `bin/main.ml` exposes only language commands.
  - analyzer/config/synthesis/test dune stanzas are disabled.
- Define initial C subset AST in `lib/language/`.
- Add C parser/printer for:
  - `int main() { ... }`
  - declarations, assignment statements, blocks, if/else, while, return
  - pure integer expressions
- Redesign Big-Step semantics around:
  - expression: state -> state * value
  - statement: state -> control
- Port synthesis sizes, prune rules, grow rules, and proof constructors to the C subset.
- Keep evaluation order deterministic left-to-right for now.
- Keep side-effect expressions, pointers, arrays, structs, calls, overflow/UB for later.

Heuristic / search cleanup

- Keep seed config-only.
- Keep `choose_n` / `trim` / `choose_for_grow` as the heuristic selection boundary.
- Remove stale TEMP comments once grow-rule-based selection is stable.
- Later: add analyzer-facing summaries and diversity-aware trimming.

Validation targets

- `dune build`
- `./attack -pp examples/simple.c` once the C parser exists
- `./attack -big examples/simple.c` once the C Big-Step semantics exists
